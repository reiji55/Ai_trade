# 日本株AI投資分析・ミニマム版

世界のニュースから資金フロー仮説を作り、日本株の予測を事前保存し、後日TOPIXとの比較で採点する手動の研究用セットです。売買判断は人間が行います。

## 使うファイル

- [Daily_Prompt.txt](Daily_Prompt.txt)：日次分析の指示（prompt-v001）
- [Memory.md](Memory.md)：次回に渡す初期記憶（mem-v000、採点実績・教訓は0件）
- [MVP_Guide.md](MVP_Guide.md)：操作手順、予測の固定、採点、結果レビュー、A/B評価

台帳はGoogle Driveの **Prediction_Ledger_MVP** を使います。2026-09-08にユーザーが指定したGoogle Sheetsを正本とし、同名のExcel原本と二重入力しません。

## 最初の1回

1. AIにDaily_Prompt.txtとMemory.mdを渡し、Web検索を使って分析する。
2. 根拠と反証を確認し、正式予測は1日最大1件。材料不足なら見送り。
3. 予測・事実・使用入力を含む日次MDを作る。この時点はDRAFT。
4. 変更防止を有効にしたGitHub Releaseに日次MDをassetとして添付し、Publishする。Immutable表示と添付を確認してLOCK。
5. 実際の公開日時をJSTで記録し、原本URLと予測を台帳へ入力する。
6. LOCK翌取引日の終値t0と、そこから20取引日後の終値t20を、株式とTOPIXで比較する。
7. 採点後に原因を検証し、新しい版のMemoryへ教訓を残す。

GitHubの通常ファイルとコミットだけでは予測原本の変更防止を完了した扱いにしません。Immutable Releaseでもタイトル・本文は編集可能で、Release全体の削除も可能です。固定対象は添付assetとタグです。削除や欠測の記録を成績から黙って除外しません。

## 公開範囲と他のAI

Privateは公開範囲の選択であり、研究の必須条件ではありません。認証付きGitHub連携に対応したAIには、このリポジトリへのアクセスを許可して共有できます。連携がない場合は必要なファイルを添付します。Publicなら公開Webを取得できるAIへURLで渡しやすくなりますが、誰でも内容を読める状態になります。

公開／非公開と、予測原本の変更防止は別の設定です。Google Sheetsの共有権限もGitHubとは別です。
